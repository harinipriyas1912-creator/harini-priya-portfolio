# Harini Priya S. — Portfolio Website

A responsive, modern blue corporate portfolio designed for GitHub Pages.

## Files
- `index.html` — website content
- `style.css` — responsive styling and visual design
- `script.js` — mobile navigation and scroll reveal effects

## Before publishing
1. Your email, phone number and LinkedIn profile have been added.
2. Replace the generic GitHub link with your GitHub profile URL once you have your username.
3. Add a real resume PDF if you want a resume download button (not included until the final resume file is supplied).
4. Add your professional photo when ready.
5. Check the college name spelling and all experience/project details before making the site public.

## Publish with GitHub Pages
1. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for the published site link to appear in the Pages section.

Your website URL will be `https://YOUR-GITHUB-USERNAME.github.io/`.

This site uses Google Fonts from Google Fonts; a network connection is needed for those fonts. It will still work with fallback fonts if unavailable.
